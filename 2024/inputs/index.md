# 2024年のインプット集

自分がクリエイターとして作るもの（アウトプット）はポートフォリオにまとまるけども、それのもとになるインプットがどのような姿をしているかはよくわからないな、と思い、2024年はそのログを取りました。

展示が44件、舞台が24件。具体的な数字で見られるインパクトはもちろんのこと、書き込む際に目に入った過去のエントリーが新たな行動につながることもしばしばありました。思えば書籍が入っていなかったり、そのとき考えたことや思ったことがわかればもっと面白いだろうなと思ったりもするので、来年以降に活かしたいと思います。

個人的な内省のためのみならず他の人にとっても、「こういうアウトプットをするクリエイターがどのようなインプットをしているのか」というデータは有益な情報になりうるのではないかと思い、ここに公開します。
